# THE CAPTAIN'S FIGHT, beat by beat. The CaptainFight node reads this file every time the fight
# starts (its Choreography File field), so a change shows up the next time you press F5.
#
# DRAFT. A first pass at the moves; reorder them, cut them, add your own.
#
# Sections:
#   === phase 1 ===             the captain (the fight's Boss), the fair fight, until the lieutenant scene
#   === phase 2 ===             the captain after he is empowered: the fight meant to be lost
#   === Lieutenant phase 1 ===  another guard in the same fight, by his node name. A guard with no
#                               section fights the usual way (close in, circle, swing).
# The beats play top to bottom. After the last one they start again from the line that says
# `loop` (or from the top if there is none). Anything after a # is a note; the game skips it.
#
# Beats (numbers are seconds unless it says metres):
#   guard 1.0           stand on guard for 1 second, watching Aeneas (a pause)
#   approach 2.0        walk until he is 2.0 metres from Aeneas (gives up after 4 seconds)
#   step_in             a quick lunge into striking range
#   back 1.5            step back 1.5 metres, still facing Aeneas
#   circle 2 left       sidestep round Aeneas for 2 seconds (left or right)
#   feint 0.5           raise the blade as if to cut, for 0.5 seconds, then lower it: no hit (baits a parry)
#   swing 0.75          one cut: his visor flashes for 0.75 seconds, then the blade lands.
#                       Block it, parry it (tap block just as it lands), or dodge.
#   combo 0.7 0.4 0.4   cuts one after another; each number is that cut's wind-up
#   heavy 1.1           a slow, hard cut that can't be blocked or parried (his coat flashes red): dodge it
#   finish 1.0          the blow that ends the fight if it lands (phase 2)
#   scene captain_taunt play that scene from data/dialogue/empty_town.txt; the fight pauses
#                       meanwhile. Each scene plays only the first time it is reached.
# Attack beats (feint, swing, combo, heavy, finish) walk into reach first if Aeneas is too far.
# Damage comes from data/enemies/agency_captain.tres (attack_damage, attack_range):
# a combo cut does 0.8 of it, a heavy 1.5. Hitting him never breaks his beat; a parry does.
